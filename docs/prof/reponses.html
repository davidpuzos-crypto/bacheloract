L’envoi des réponses est désactivé

Dans docs/data/config.json, la ligne "actif" de la partie "collecte" est à false. Remettez-la à true pour recevoir les réponses ici.

Votre code

Le code enseignant ouvre les réponses, chiffrées pour vous seul·e. Majuscules, espaces et tirets ne comptent pas.

Suivi des équipes

Heure de départ pour toute la classe

Les appareils des équipes et l’écran de projection relisent l’heure toutes les six minutes au plus. Le plus simple est de la diffuser avant l’arrivée des étudiant·es.

Où passent les réponses, et combien de temps elles restent

Chaque navigateur chiffre les réponses de son équipe avant de les envoyer à un relais public gratuit, ntfy.sh, qui ne demande aucun compte. Le relais ne voit que des données illisibles. Seul votre code permet de les lire, sur cette page.

Le relais garde les messages 12 heures. Cette page en garde une copie dans ce navigateur à chaque actualisation. Après la séance, téléchargez les réponses pour les conserver.

Le relais accepte 250 messages par jour depuis un même réseau, et toute la classe partage souvent le même. Les équipes envoient donc aux moments clés (fin de chaque étape, demande d’aide, dépôt), et seulement ce qui a changé.
